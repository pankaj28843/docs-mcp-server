# TP Playbook Angular documentation coverage

This reference records an isolated onboarding experiment on 2026-11-02. The example deployment contains candidate tenants; adding them to a deployment, syncing them, and exporting their data are separate operations. The experiment did not modify the shared deployment or data.

## Versions and sources

TP Playbook's `frontend/package-lock.json` locks Angular core 22.2.4, CLI 22.2.5, Angular Material and CDK 22.2.4, angular-eslint 22.6.0, and RxJS 7.8.2. Its manifest uses ranges for some packages. The official [Angular release policy](https://angular.dev/reference/releases) identifies v22 as current at the time of this experiment; the unversioned site moves with the current release and is not a permanent 22.2.4 snapshot. [Angular v21](https://v21.angular.dev/) and [Angular v20](https://v20.angular.dev/) have separate sites; neither was indexed in this experiment.

## Retrieval evidence

The isolated Angular online sync finished with 1,647 successful pages, zero pending pages, zero queued pages and zero failed URLs. The index persisted 1,647 documents at 18:03 UTC. The official sitemap listed 1,626 URLs; the additional pages came from the configured entries and the resumed queue. A search for `Angular routing route guards` returned [Control route access with guards](https://angular.dev/guide/routing/route-guards), and fetch returned the guide. A search for `ng build application builder` returned the CLI builder guide; fetch of [ng build](https://angular.dev/cli/build) returned its command reference. `CDK drag drop` returned the [drag and drop guide](https://angular.dev/guide/drag-drop) and [CDK_DROP_LIST API](https://angular.dev/api/cdk/drag-drop/CDK_DROP_LIST); fetch returned the API description.

The Git snapshots also completed sync and indexing. `alt-text accessibility` returned and fetched `packages/eslint-plugin-template/docs/rules/alt-text.md`; `MatDialog open dialog` returned and fetched `src/material/dialog/dialog.md`; `CDK overlay scroll strategy` returned `src/cdk/overlay/scroll/scroll-strategy.md`; and `Observable subscribe` returned and fetched `guide/observable.md`. All six tenant datasets were exported from the isolated data directory. Results are bounded by the indexed sources above; a matching query is not a completeness test.

## Known gaps and follow-up

- [Angular Material](https://material.angular.dev/) and [RxJS](https://rxjs.dev/) are JavaScript-rendered. Online discovery from their ordinary component and guide routes failed to extract pages in this server, although a headed browser rendered them. Do not treat the Git guide tenants as complete API coverage.
- Material's generated reference has HTML fragments such as [material-dialog](https://material.angular.dev/docs-content/api-docs/material-dialog). Enumerating names from tagged Material/CDK source directories found 95 valid fragment seeds among 126 candidates; this is not a verified complete published inventory. Even with `enable_crawler: false`, entry-based sync performs link discovery. Some relative links resolve to missing slash-form URLs under `api-docs/cdk/`, `api-docs/material/` and `api-docs/components/`; the example excludes those prefixes. A fresh isolated sync completed with 95 successful, zero pending and zero failed URLs; 95 Markdown documents contained no `# Page Not Found` heading. Search and fetch returned substantive Material dialog and CDK overlay APIs. Revalidate discoveries, exclusions and source version on refresh; the current-site seeds do not establish version-pinned completeness.
- The `rxjs-api` filesystem tenant needs the [companion snapshot exporter](https://github.com/pankaj28843/docs-mcp-server/pull/81). After that change is available, run `uv run python scripts/rxjs_api_snapshot.py --output-dir ./mcp-data/rxjs-api/api-snapshot --expected-version 7.8.2`, then index `rxjs-api`. The isolated snapshot contained 371 documents; `switchMap cancels previous inner observable` ranked the canonical [switchMap API](https://rxjs.dev/api/operators/switchMap) first, and fetch returned its description. The captured manifest records version 7.8.2 and collection time; the filesystem index reports freshness as unknown. The fetch result reported 4,096 original characters, so this check does not establish full-page retrieval.
- Versioned Angular v20/v21, versioned Material/CDK, older angular-eslint tags, and complete Material APIs remain unindexed. Use the official sites and repositories above until separately ingested and verified. The existing TypeScript tenant also needs a separate version and completeness audit against TP Playbook's locked 6.0.3.

For a deployed copy, re-run sync, indexing and export against its own configuration and data directory, then use `docsearch search` and `docsearch fetch` on the examples above. Record the index timestamp, source version and failures; do not infer freshness from this historical experiment.
